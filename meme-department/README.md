# Meme Department

A static, responsive meme-trend field guide with a Philippine politics satire page and a small meme caption generator.

## Run locally

Open `index.html` in a browser, or run any static file server from this folder.

## Deploy to Vercel

Import this Git repository in Vercel. It is a static site: no build command or framework preset is required. The site entry point is `index.html`.

Trend data is an editorial snapshot checked November 21, 2026, with source links in the page. The caption generator runs in the browser and does not send input anywhere.
